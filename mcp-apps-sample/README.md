# MCP Apps Sample: Server Only

MCP server with interactive UI resources powered by Amazon Bedrock.

## Features

- 📊 **Data Visualization**: D3.js charts generated by agent
- 📋 **Data Tables**: Sortable, filterable tables
- 🎨 **Custom Widgets**: Interactive HTML/JS applications
- 🔄 **Bidirectional Communication**: postMessage between app and client

## Architecture

```
┌──────────────────────────────────────┐
│   MCP Client (Your Choice)          │
│   - VS Code                          │
│   - Claude Desktop                   │
│   - Cursor                           │
└──────────────┬───────────────────────┘
               │
               ↓  MCP Protocol (SSE)
┌──────────────────────────────────────┐
│   MCP Server (Python)                │
│   - Tools with UI resources          │
│   - Bedrock Integration              │
│   - Port 3003                        │
└──────────────────────────────────────┘
```

## Tech Stack

- **Server**: Python + FastAPI + MCP SDK
- **Agent**: Amazon Bedrock Claude
- **UI**: HTML/CSS/JS (D3.js, vanilla JS)
- **Protocol**: MCP with UI extensions

## Setup

### Local Development

```bash
pip install -r requirements.txt
python server.py
```

### Docker

```bash
docker build -t mcp-apps-sample .
docker run -p 3003:3003 \
  -e AWS_ACCESS_KEY_ID=xxx \
  -e AWS_SECRET_ACCESS_KEY=xxx \
  -e AWS_REGION=us-east-1 \
  mcp-apps-sample
```

## Environment Variables

```env
AWS_ACCESS_KEY_ID=your_key
AWS_SECRET_ACCESS_KEY=your_secret
AWS_REGION=us-east-1
BEDROCK_MODEL=anthropic.claude-3-5-sonnet-20241022-v2:0
```

## Usage with VS Code

1. Install MCP extension for VS Code
2. Add server configuration to `.vscode/settings.json`:

```json
{
  "mcp.servers": {
    "agent-ui-sample": {
      "command": "python",
      "args": ["/path/to/server.py"],
      "env": {
        "AWS_ACCESS_KEY_ID": "your_key",
        "AWS_SECRET_ACCESS_KEY": "your_secret"
      }
    }
  }
}
```

3. Open command palette: "MCP: Connect to Server"
4. Select "agent-ui-sample"

## Available Tools

### create_chart
Generate interactive D3.js chart visualization.

**Parameters:**
- `data`: Array of numbers
- `labels`: Array of labels (optional)
- `type`: "bar" | "line" | "pie"

**Returns**: UI resource URL

### create_table
Generate sortable data table.

**Parameters:**
- `data`: Array of objects
- `columns`: Array of column definitions

**Returns**: UI resource URL

### create_widget
Generate custom interactive widget.

**Parameters:**
- `html`: HTML content
- `css`: CSS styles (optional)
- `js`: JavaScript code (optional)

**Returns**: UI resource URL

## How It Works

1. **Tool Registration**: Server exposes tools with `_meta.ui.resourceUri`
2. **Agent Calls Tool**: Bedrock agent decides to visualize data
3. **Resource Generation**: Server generates HTML/JS UI
4. **Client Renders**: MCP client fetches `ui://` resource
5. **Sandboxed Display**: UI renders in iframe with postMessage

## Example Interaction

**User**: "Visualize this data: [10, 25, 15, 30]"

**Agent**: Calls `create_chart` tool

**Server**: Generates D3.js bar chart HTML

**Client**: Renders interactive chart in chat

## Key Files

- `server.py` - MCP server with FastAPI
- `tools.py` - Tool definitions and handlers
- `ui_generator.py` - HTML/JS generator
- `templates/` - UI templates (charts, tables)

## Security

- All UI runs in sandboxed iframes
- CSP headers prevent XSS
- No arbitrary code execution
- postMessage for controlled communication

## Customization

### Add New Tool

Edit `tools.py`:

```python
@mcp_server.tool()
async def my_custom_tool(param: str) -> str:
    ui_html = generate_ui(param)
    ui_id = save_ui(ui_html)
    return f"ui://{ui_id}"
```

### Add UI Template

Create `templates/my_template.html`:

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Custom Widget</title>
  </head>
  <body>
    <!-- Your UI here -->
  </body>
</html>
```

## Differences from AG-UI and A2UI

- **AG-UI**: Pre-built components, controlled
- **A2UI**: JSON structure, balanced
- **MCP Apps**: Full HTML/JS, maximum freedom

MCP Apps gives agents complete control over UI generation but requires sandboxing and security measures.
